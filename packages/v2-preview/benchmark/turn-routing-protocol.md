The seven-arm native roster is frozen before model use. Two exact controls from the earlier native Willow Yard run are linked by receipt hash. A new routed compact Willow Yard arm is a historical regression comparison. Birch Siding and Larch Depot each run all three arms in rotating natural-long order. They test signed transfer reconciliation with calibration versioning, and incomplete custody with a conflicting unsigned tally and repeated reservations.

All arms use the original long-session context, caps, isolated native project, automatic compaction, scoped sources, and shared root schedule. Focused Build and routed compact ALG each get the same fresh checker prompt, with a dynamic advisory of verified checker paths. The treatment enables the existing `alg_investigation` tool with `graphLoop: true` and `turnRouting: "routed-compact"`. Paid inference uses OpenCode 2.3.2 and Luna through the native OpenCode account path. Each assigned arm runs once.

The primary incident grade uses the natural-long checker and strict submission JSON. Its finding parser accepts recognized aliases. A repeated supported target can satisfy the same target once. Extra references can pass when they resolve and the root verified their source paths. Unknown or open-ended claims may require independent adjudication. Blind secondary review is separate and uses the original root reads. Unobserved final closure is unknown. A verified automatic boundary requires an automatic host compaction, matching provider summary receipt, and subsequent root input containing that summary. Token metrics use observed native input totals including cache and show missing receipts. Script pressure is synthetic.

The trace includes actions, schema bytes and active-schema bytes per turn, source and duplicate-read counts, automatic boundaries, skill delivery, and calibrated recall. Catalog discovery requires a prior distinct catalog response visible on the bridge wire. A recall receipt must cite the exact row from the early root read, and its interpretation must match the labeled calibration values. Willow's original prompt gives a fixed finding ID, so its catalog use is a regression witness. The held-outs leave the finding ID to the model. An arm can answer correctly through source verification even if it elects not to use saved state. Native traces alone cannot attribute an incident-grade difference to routing versus choices made by the model.

## Local scripted qualification

From the repository root, supply a native OpenCode 2.3.2 executable and a staged preview package. On Windows the command defaults to the pinned final binary and package alongside the shared worktree. On Linux use the same command with explicit Linux paths.

```sh
bun packages/v2-preview/benchmark/turn-routing-run.ts --qualify NEW_OUTPUT_DIR --host OPENCODE_BINARY --package STAGED_PREVIEW
```

The scripted roster includes the same seven new trials. It uses a loopback-only fake model and needs no historical private receipts or credentials. It tests catalog-to-detail recall after automatic compaction, validates procedure delivery, and calculates bridge units using the gross from the user turn and operands recovered from the source or lookup output. The fixture's scripted final answers exercise scoring and transport. Model incident-solving accuracy comes from the native trial.

Freeze and native replay require the archived natural-long freeze, terminal receipt chain, exact prior runtime, and staged final bundle. The original natural-long host has an opt-in adapter. Without that adapter, it retains the original configuration, prompts and receipt shape. Use the pinned prior revision for byte-exact historical source reproduction. The new freeze records the original host hash through its archived protocol and verifies the exact original Willow prompt events and both terminal controls.

```sh
bun packages/v2-preview/benchmark/turn-routing-run.ts --freeze NEW_FREEZE_JSON --qualification QUALIFICATION_OUTPUT/report.json
```

After explicit GO, use the frozen artifact with `--frozen FILE --allow-model-calls --out NEW_OUTPUT_DIR`. The live run reserves the freeze before credential staging and writes a journal, terminal receipt per assigned arm, and report. Keep the original freeze path and reservation together.


Generate the compact native readout from the terminal output directory. The reader verifies the recorded hashes and arm journal before writing.

```sh
bun packages/v2-preview/benchmark/turn-routing-readout.ts NATIVE_OUTPUT_DIR NEW_EVIDENCE_MD
```
