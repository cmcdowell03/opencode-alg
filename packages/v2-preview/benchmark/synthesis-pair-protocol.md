# Preview.13 live synthesis comparison

The primary question is whether a routed ALG owner on OpenCode 2.3.2 finishes a new long-running incident accurately when the user describes the job in ordinary language. Both arms receive the same skills, read-only synthetic sources, six intervening tasks, and independent focused checker. The ALG arm can discover its investigation tool. User prompts contain neither its name nor finding IDs. The model is Luna in both roles. The installed plugin is model agnostic.

Riverbend compares focused Build first and routed ALG second. Each arm has an 8,192-token context and a 48-provider-call ceiling including summary and checker calls. Native compaction is automatic. A missing final fails the incident. Keep every assignment and all early stops. Score material defects, disposition, missing evidence and exact citations against verified root reads. An independent reviewer sees anonymized answers and source rows before anyone interprets the traces. The initial machine grade and blinded result are both retained.

Freeze Northline at the same time as Riverbend. Open it only if primary ALG completes, passes the blinded incident grade, and returns the correct opening seal, procedure and conversion after the intervening tasks. Reverse the arm order. Replace the designated source once after the bridge. Both root and checker receive the same correction notice and access the same revised source. The final-version receipt is needed for citations to that file. One decisive record remains unavailable.

After grading, trace the calibration from the opening read, through applied compaction summaries and authorized graph or source receipts, to the later answer. Record root and checker calls, repeated reads, actual synthesis use, final status calls, and provider-reported tokens. A boundary count alone cannot establish loss. Correct recovery after a reread, correct recovery without a reread, an incorrect answer despite visible evidence, and unavailable observations are distinct outcomes.

Run the following steps against the same study directory and host/package paths. The CLI accepts `--mode qualify`, then `--mode freeze`, then `--mode live --stage primary --allow-model-calls`. Each command requires `--study DIR --host OPENCODE_BINARY --package PREVIEW_BUNDLE`. Qualification uses a local scripted provider. Keep the freeze, its one-shot reservation and the private native receipts together. Use the paired review CLI's `packet` and `apply` commands on `DIR/primary-live` and write the review to `DIR/primary-review.json`. When eligible, run `--mode live --stage conditional --allow-model-calls` once. These are matched diagnostic incidents with one run per condition.
