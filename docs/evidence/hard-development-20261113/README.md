# First expanded hard development cohort

This package preserves the terminal results from frozen source `7764686`,
the prospective plan and apparatus qualification, and a **separate posthoc
diagnostic**. `manifest.json` identifies the exact copied bytes. Raw per-arm
messages, service ledgers, project files and progress remain preserved in the
local `implementation-evidence/hard-d50-terra` directory. The posthoc audit pins
the raw results and observed project artifacts it read; it did not overwrite
their scores or mutate the frozen files.

- Twelve issued arms; eleven completed, one telemetry stop.
- All owned-process/service cleanup and temporary authentication-copy removal
  passed. Source and user-global configuration stayed unchanged.
- The original aggregate scores are not a trustworthy comparative solve rate:
  timestamp representation and omitted code-runner dependencies created false
  negatives. The API-recovery public artifact contract also requires review.
- The diagnostic accepts all eight factory/code artifacts after those two
  apparatus repairs. It does not turn ALG's four scope-blocked runs into
  completed verification or repair the incomplete telemetry census.
- The original restart-recovery case passed for ALG and failed for Build.
  This is one paired outcome, not general superiority.
- No compaction-loss rate was measured. Eleven complete censuses had zero
  compactions; one incomplete census had zero observed markers only.

See [the findings](../../v1-hard-development-findings.md) for production defects,
limits and the next qualification boundary. The development child code runner
uses the same OS user; neither this cohort nor its diagnostic is isolated
confirmation. The scorer does not use ALG's own verdict as its truth source.
