## Qualifications and disagreements

**Keep the broader vision.** Semiconductor investigations and artifact building were explicit user requests. Their presence is not itself evidence of scope drift. The correction is delivery order and clear dependencies, not deleting them.

**Logs nominate evaluation cases; they do not validate themselves.** Solved incidents and reminders still need expected outcomes, a trustworthy verifier, permitted data, source snapshots and leakage review. If later knowledge cannot be excluded, label the replay hindsight-assisted. Do not claim those cases establish prospective causal performance.

**Git merge is conditional approval evidence.** It is useful only when the independent review, branch controls and authenticated deployed source required by operator policy are enforced. A merge or checked-in requirement cannot grant itself runtime permissions. Offline packages need an explicitly approved revision/inventory.

**Local absence is not global absence.** The review's narrow file searches did not locate a datalake repository, but that does not establish that the MCP service is unavailable. Its one local SKILL.md count covers only the searched locations. The latest command evidence does not establish a global lifetime count of validated candidates. These observations cannot justify broad claims about the deployed air-gapped environment.

**Uncertainty is not a relaxation of integrity.** Model variability warrants calibrated comparisons and inconclusive results, not tolerance for permission violations, corrupted evidence or deterministic correctness failures. A one-case deployment probe establishes limited compatibility, not reliability or causal accuracy.

**Do not promise a duration before qualification.** Service identity, job guarantees, model behavior and deployment constraints are still open. Size the implementation after the narrow capability check; no “about a day” commitment follows from the review.
